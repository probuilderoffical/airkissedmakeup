# AirKissed Makeup Website

Premium, responsive one-page website for **AirKissed Makeup** in Houston, Texas.

## Live site
Designed for GitHub Pages at:
`https://probuilderoffical.github.io/airkissedmakeup/`

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Save. GitHub will publish the static site automatically.

No Node, npm, build process, or server is required.

## Structure
- `index.html` — page content, SEO, structured local-business data
- `styles.css` — responsive visual system and animations
- `script.js` — navigation, reveal effects, accordion behavior
- `assets/brand-mark.svg` — custom lightweight brand mark
- `site.webmanifest` — install/browser metadata
- `robots.txt` + `sitemap.xml` — search-engine basics
- `.nojekyll` — ensures GitHub Pages serves files as-is

## Business details used
Publicly listed AirKissed Makeup details were used for the initial build. Service availability, prices, opening hours and review counts can change, so update the site whenever the business listing changes.

## Images
Editorial beauty imagery is loaded from Unsplash and credited in the website footer. Replace with AirKissed Makeup's own portfolio photography whenever available for the strongest conversion and brand authenticity.
